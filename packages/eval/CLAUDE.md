# packages/eval (B)

Labeled synthetic disputes and the harness that scores strategies on the production code path.

- Cases: `cases/H*.json` (hand-written, edit the JSON) and `cases/G*.json` (generated by `pnpm eval:generate`; don't edit, regenerate). Schema in `src/schema.ts`.
- `pnpm eval` writes `reports/<ts>.json`, `reports/latest.json` and `docs/eval-report.{md,html}`. `--llm` runs the Claude rows under `--budget-usd` (default $5) and caches to `cache/llm-triage.json`.
- Never tune on the test split: `split()` is fixed and calibration (`calibrateCv`) only sees train.
- Blind labels go in `labels/<name>.json` via `pnpm eval:label <name>`; `pnpm eval:agreement` for kappa.
- Report numbers honestly: lead with held-out results; recovered dollars from one outcome per case are noisy.
